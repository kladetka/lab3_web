# Лабораторна робота №3 — Основні теги HTML

## Структура
- `index.html` — головна сторінка.
- `project_parts/table.html` — завдання 1.
- `project_parts/mondrian.html` — завдання 2.
- `project_parts/schedule.html` — завдання 3.
- `project_parts/questionnaire.html` — завдання 4.
- `project_parts/map.html` — завдання 5.
- `img/` — зображення для сторінок.
- `audio/` — папка для аудіофайлів.
- `answers.txt` — відповіді на контрольні питання.

## Як запустити
1. Розпакувати архів.
2. Відкрити файл `index.html` у браузері.
3. З головної сторінки відкрити кожне завдання.
4. Для здачі завантажити всю папку проєкту до особистого Git-репозиторію.

## Важливо
Розклад у `schedule.html` є демонстраційним, тому перед здачею його можна замінити на свій фактичний розклад.

У `map.html` використано карту України з Інтернету та HTML image map (`<map>` + `<area>`). Для повної відповідності вимозі викладача координати областей можна уточнити в Image Map Generator.
