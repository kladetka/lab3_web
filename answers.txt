Контрольні питання — Лабораторна робота №3

1. HTML (HyperText Markup Language) — мова розмітки гіпертексту. Вона використовується для створення структури та вмісту веб-сторінок.

2. Базова структура: <!doctype html>, <html>, <head>, <meta>, <title>, <body>. У <head> розміщується службова інформація, у <body> — видимий вміст сторінки.

3. Для гіперпосилання використовується тег <a>. Щоб відкрити його в новій вкладці, застосовують target="_blank".

4. Для заголовків використовують <h1>–<h6>. В HTML існує 6 рівнів заголовків.

5. <ul> створює маркований список, а <ol> — нумерований список. Елементи списку задаються тегом <li>.

6. Для зображення використовується <img>. Основні атрибути: src — шлях до зображення, alt — альтернативний текст, width і height — розміри.

7. Таблиця створюється тегом <table>. <tr> — рядок, <th> — заголовкова комірка, <td> — звичайна комірка.

8. Для абзацу використовується тег <p>.

9. Форма створюється тегом <form>. Основні елементи: <input>, <textarea>, <select>, <option>, <button>, <label>, <fieldset>, <legend>. Основні атрибути: action, method, name, value, type, required, placeholder.

10. Семантична розмітка — використання тегів, які описують зміст і роль частини сторінки, наприклад <header>, <nav>, <main>, <section>, <article>, <footer>. Вона покращує доступність і допомагає пошуковим системам краще розуміти структуру сторінки.
